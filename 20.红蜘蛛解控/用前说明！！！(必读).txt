打卡软件 unControl

注: 无标题窗口 为 1号 ，解控端窗口 为 2号

1.远程服务器 IP 去指定已开启 2号 的电脑 或 自己开启 2号

2.开启服务器 按 Ctrl + P 会弹出对话框
  下面有数字，密码：该数字取反(该数字类型为 字节)
  例：not 100 -> 155 ; not 0 -> 255

3.如果 2号 的控制端口 和 教师 IP 符合，直接在 1号 打开“自动解控(关闭)”，挂着就行。
  如果你被控了，又退出来了，请点击“窗口化”。

4.在教师信息框中输入教师 IP ，点击“抓取(关闭)”自动抓取老师主机名 或者
  点 2号 里的 “扫描(关闭)”抓取整个机房的 IP 和 主机名
  如果知道教师 IP 和主机名直接输入为 窗口调节 做准备。

5.等窗口有教师演示画面时 点击“窗口调节”

6.不建议给自己 和 大家 开启聊天服务，后果自负！！！

如果你联网了，上述所以功能将不能使用！！！
