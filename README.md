# 📼 职高三年 · VB6 编程回忆录

> 这是一个封存了职高三年（2022-2025）编程记忆的代码仓库。
> 这里没有优雅的架构，只有那个年代特有的少年心气和充满时代感的“野路子”实践。从对抗机房监控软件的“红蜘蛛解控”、“极域破解”，到童年回忆复刻的“坦克大战”，再到各种未完成的实验性项目，每一个文件夹都是青春的一个切片。

---

### 📂 项目简介

所有核心项目均使用古老的 **Visual Basic 6.0** 编写。这不仅仅是代码，更是从最初只会拖控件，到后来尝试调用 Windows API、对抗机房监控软件（红蜘蛛、极域）的技术探索实录。

仓库中还混杂了一些 **HTML、CSS、JavaScript** 文件。这些并非我编写的网页，而是当年在学校机房冒着风险偷偷上网，将一个个网页保存到硬盘上供离线研读的“战利品”。它们是我在那个信息闭塞的局域网里，窥探广阔互联网世界的窗口。

### 🛠️ 仓库特点

- **技术栈**：Visual Basic 6.0 (经典怀旧)
- **代码风格**：充满个人印记，变量命名随意（拼音警告），逻辑简单直接
- **项目状态**：大部分为实验性项目，部分已烂尾或仅作学习用途
- **核心价值**：记录一个编程初学者在特定环境下的技术探索与成长轨迹

### 📝 特别说明

这些代码是特定时代和个人成长阶段的产物，包含大量不规范的编程实践。上传此仓库旨在记录和分享一段独特的编程学习经历，而非作为生产环境的参考代码。

### 📚 参考资料与启蒙读物

本仓库所有的开发与技术探索，主要依托于以下经典资料。在那个没有 AI 辅助、资源有限的条件下，这些厚重的书籍和离线文档以及“偷”来的网页代码，就是我唯一的导师。

- **MSDN for VB6.0**
    - Visual Basic 6.0 官方开发者网络文档（离线版），涵盖了语言语法、控件详解及基础库函数说明，是当年最权威的“字典”。
- **Power Builder Win32 API 程序设计基础（初级卷）**
    - 系统讲解 Win32 API 在 Power Builder 环境下的基础调用方法，虽然语言不同，但为理解跨语言 API 探索提供了核心思路。
- **Power Builder Win32 API 程序设计基础（高级卷）**
    - 深入探讨 API 高级特性，如窗口管理、Hook劫持等，是突破 VB6 原生功能限制、实现机房破解与底层 Hook 的关键灵感来源。
- **Power Builder Win32 API 程序设计参考手册**
    - API 函数速查工具，提供详尽的参数说明、返回值定义及典型调用示例，是当年调试代码和进行逆向分析的重要案头书。
- **HTML、CSS、JavaScript 文件**
    - 仓库中收录的各类网页源码，是我当年在学校机房偷偷上网时保存到硬盘上的“战利品”。这些代码见证了我如何通过“偷师”和离线研读，在没有互联网的时代探索 Web 前端技术。
