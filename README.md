# 📼 职高三年 · VB6 编程回忆录

> 这是一个封存了职高三年（2022-2025）编程记忆的代码仓库。
> 这里没有优雅的架构，只有那个年代特有的少年心气和充满时代感的“野路子”实践。从对抗机房监控软件的“红蜘蛛解控”、“极域破解”，到童年回忆复刻的“坦克大战”，再到各种未完成的实验性项目，每一个文件夹都是青春的一个切片。

---

### 📂 项目简介

所有核心项目均使用古老的 **Visual Basic 6.0** 编写。这不仅仅是代码，更是从最初只会拖控件，到后来尝试调用 Windows API、对抗机房监控软件（红蜘蛛、极域）的技术探索实录。

仓库中还混杂了一些 **HTML、CSS、JavaScript** 文件。这些并非我编写的网页，而是当年在学校机房冒着风险偷偷上网，将一个个网页保存到硬盘上供离线研读的“战利品”。它们是我在那个信息闭塞的局域网里，窥探广阔互联网世界的窗口。

### 🛠️ 仓库特点

- **技术栈**：Visual Basic 6.0 (经典怀旧)
- **代码风格**：充满个人印记，变量命名随意（拼音警告），逻辑简单直接
- **项目状态**：大部分为实验性项目，部分已烂尾或仅作学习用途
- **核心价值**：记录一个编程初学者在特定环境下的技术探索与成长轨迹

### 🎮 项目精选

| 类别 | 代表项目 |
| :--- | :--- |

### 📝 特别说明

这些代码是特定时代和个人成长阶段的产物，包含大量不规范的编程实践。上传此仓库旨在记录和分享一段独特的编程学习经历，而非作为生产环境的参考代码。
